# ChatWithExcelFile — beta test cases

Use these two Damodaran workbooks. They are the same family as items
**2, 10, 11, and 19** on
https://exinfm.com/free_spreadsheets.html
(Rating, FCFF Valuation, WACC). If an exinfm `.xls` link is dead, use
the current NYU files below. Do **not** use item 6 (macros), item 30
(exe), or item 41 (macros).

Ask in **English**. One new chat per workbook. Attach the file once.
Copy the first inventory turn; every later answer is checked against
that list. Do not paste a model formula into Excel without that check.

How to tell which path ran:

| What you see | Path |
| --- | --- |
| Instant answer. No spinner. No “Generated in …” | Inventory lookup |
| Spinner, wait copy, then “Generated by … in … min” | Local model |

Load model **before** the model questions. Lookup still works if the
model is unloaded.

## File A — WACC calculator (exinfm #19)

Download:

https://pages.stern.nyu.edu/~adamodar/pc/wacccalc.xls

Save as `wacccalc.xls` (or `.xlsx` if Excel converts it). Attach that
**one file**. Model may stay unloaded for A1–A5.

### Inventory lookup (must be instant)

Type these lines **exactly**:

1. `List the named ranges from the inventory.`
2. `Are there external workbook links in the inventory?`
3. `Where is WACC or the cost of capital computed?`
4. Open the inventory turn, pick one listed cell, then ask  
   `What does [SheetName]!A1 do?`  
   (replace with the real sheet and cell from the list)
5. `What does Input!Z999 do?`  
   (a cell that is not in the list — expect “not in the inventory”)

**Pass:** no spinner; no invented cells; A2 is none or a real listed
link; A5 does not invent a formula.

### Model (Load model first, then spinner)

6. `How is the cost of capital calculated? Quote only a formula that is in the inventory.`
7. `Suggest a paste-ready WACC formula only if the inventory already shows that logic.`

**Pass:** listed cells match the inventory turn. Fail if a new `=`
formula is presented as stored. A labelled **SUGGESTED FORMULA** may
be wrong — note it, do not treat it as Excel truth.

## File B — FCFF “ginzu” (exinfm #10 / #11, current all-in-one)

Download:

https://pages.stern.nyu.edu/~adamodar/pc/fcffsimpleginzu.xlsx

Save as `fcffsimpleginzu.xlsx`. **New chat.** Attach this file only.

This workbook is large (many sheets, many formulas). The English
inventory lists a ranked subset. That is expected.

### Inventory lookup (instant)

1. `List the named ranges from the inventory.`
2. `Are there external workbook links in the inventory?`
3. `Where is WACC or the cost of capital computed?`  
   Expect cells such as cost of capital / Input sheet, not a dump of
   every sheet name.
4. From the inventory list, pick a real FCFF or terminal-value cell,
   then: `What does [SheetName]!A1 do?`
5. `What does Valuation output!B999 do?`  
   Expect not in the inventory.

**Pass:** same rules as File A. A3 should stay a short ranked list.

### Model (Load model, spinner)

6. `How is terminal value calculated? Quote only a formula that is in the inventory.`
7. `Explain the cost of capital logic in plain English.`  
   (no `Sheet!A1` in this question — it must hit the model)
8. `Suggest a paste-ready FCFF-from-EBIT formula only if the inventory shows that logic.`

**Pass for 6–7:** mentions listed cells (often terminal value / cost of
capital rows from the inventory). Extra textbook gloss is a note, not
an automatic fail.

**Fail for 8:** a paste-ready `=` that is **not** in the inventory,
presented as the official FCFF. Honest “not in the inventory” is a
pass. A **SUGGESTED FORMULA** that is clearly labelled as new is mixed:
record the exact text.

## What to send back (one page)

For each question: path (instant vs spinner), elapsed time if spinner,
pass / fail / mixed, and one sentence. Attach a screenshot of the
inventory turn if lookup invented a cell.

We will use this to decide the next product step (tighter lookup,
stronger grounding, or a later interpreter). Do not ask the prototype
to recalculate Excel, run macros, or build charts.
